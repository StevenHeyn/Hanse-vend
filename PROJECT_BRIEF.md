# HANSE VEND – Website Relaunch

Premium B2B website for HANSE VEND (ViaCash GmbH).

## Positioning
- Regional vending full-service: Hamburg and Schleswig-Holstein
- Custom vending projects: Germany-wide
- Primary conversion: qualified location inquiries
- Contact: info@hanse-vend.de

## Design
- Midnight: `#111B24`
- Deep Teal: `#183E48`
- Mint: `#69D5C4`
- Cloud: `#F3F6F7`

## Planned stack
React, TypeScript, Tailwind CSS, responsive component architecture. Hosting and deployment will be configured separately.

## Homepage sections
1. Hero: “Automatenlösungen, die einfach funktionieren.”
2. Service benefits
3. Snack, beverage, coffee and custom vending solutions
4. Regional full-service / nationwide projects
5. Industry solutions
6. Four-step process
7. Cashless payment, telemetry and technology
8. Verified project references
9. Multi-step location inquiry
10. FAQ
11. Closing CTA and footer

## Lead flow
Validate on the server, apply spam protection, then send inquiries to `info@hanse-vend.de` via a server-side email provider. Never store credentials in the repository or pretend an unconfigured form has sent an email.

## Launch requirements
- No invented testimonials, customers, performance metrics or service guarantees
- Review legal pages and privacy information
- SEO metadata, sitemap, canonical URLs and 301 redirects
- Responsive, accessible UI and Core Web Vitals optimization
- Preserve the existing live site until explicit approval for cutover

Initial project brief. Application implementation pending.
